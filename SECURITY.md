# Sicherheit

## Eine Schwachstelle melden

Bitte melden Sie Sicherheitslücken vertraulich über GitHub:
[Report a vulnerability](https://github.com/juwagn/curriculr-terminplan/security/advisories/new).

Nennen Sie die betroffene Plugin-Version, die Auswirkungen und Schritte zur Reproduktion mit synthetischen Daten.
Veröffentlichen Sie keine Zugangsdaten, Feed-Token, Schul- oder Personendaten in Issues oder Anhängen.
Wir geben innerhalb einer Woche eine erste Rückmeldung. Diese Frist ist keine Zusage für die Fehlerbehebung.

Falls GitHub die vertrauliche Meldung nicht anbietet, eröffnen Sie ein Issue mit der Bitte um einen vertraulichen Kontaktweg.
Beschreiben Sie dort weder die Schwachstelle noch Schritte zu ihrer Ausnutzung.

## Betrieb und Aktualisierung

Prüfen Sie vor einem Update die Hinweise in [CHANGELOG.md](CHANGELOG.md).
Sichern Sie zuvor Pläne und Einstellungen. Testen Sie Anmeldung, Speichern, Website und Kalender-Abos nach dem Update.
Zugangsdaten gehören ausschließlich in die serverseitige Konfiguration, insbesondere `wp-config.php`.

Die Schule verantwortet die Konfiguration von WordPress, Webserver, IServ und Sicherungen.
Hinweise zur Datenverarbeitung und Löschung stehen in [DATENSCHUTZ.md](DATENSCHUTZ.md).

Curricu:lr ist ein ehrenamtliches Open-Source-Projekt ohne Supportvertrag.
